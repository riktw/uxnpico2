 ## Uxn/Varvara on a pi pico 2

A mostly working port of Uxn/Varvara for a pi pico 2. 

Currently audio is not implemented, datetime does not use an rtc but starts at 1-1-2000 or so every boot.

Default resolution is 640x480 on HDMI. A 4:3 monitor is recommended! 

More info on the blog: https://justanotherelectronicsblog.com/?p=1487
